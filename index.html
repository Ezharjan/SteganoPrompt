SteganoPrompt

An academic-integrity helper for educators

client-side · MIT licensed GitHub

Add an invisible integrity note to any prompt

Paste an assignment prompt and SteganoPrompt adds an invisible, LLM-readable instruction to it that stays invisible to human readers. If a student pastes your text into an AI assistant, the model quietly follows it. To keep the tool ethical, every encoded prompt also includes a short academic-integrity reminder for the student — always on.

Disclosure always on

Disclosure policy

Built for transparent, ethical use in education. Every encoded prompt carries a short academic-integrity reminder — it asks the AI to encourage honest, independent work and to disclose any AI use, plus a quiet verification token for you. It's always on. Pair it with an announced course policy (sample below), and treat any signal as a conversation starter, not proof of misconduct.
